BugGenie is a Chrome extension designed to simplify and streamline the software bug reporting process for QA engineers. It helps capture essential bug details, record user interactions, take screenshots, and organize collected information into structured bug reports.

By reducing manual documentation efforts, BugGenie helps improve QA efficiency and provides developers with clear, actionable information to reproduce, analyze, and resolve defects faster.

✨ Key Features

📸 Screenshot Capture: Capture the current browser screen to provide visual evidence of reported issues.

🎬 User Interaction Recording: Track user actions during testing to help reproduce defects accurately.

📝 Bug Description: Add a clear description of the issue.

✅ Expected Result: Define and edit the expected behavior of the functionality under test.

🔍 Actual Result: Document the actual behavior observed during testing.

🧭 Automatic Context Capture: Collect relevant information such as the current page URL, page title, browser details, and report timestamp.

📋 Automated Reproduction Steps: Generate organized reproduction steps from recorded user interactions.

📹 Video Recording Support: Capture testing session recordings when supported by the extension.

📄 Structured Bug Reports: Organize captured information into a consistent bug report format.

📋 Quick Report Copying: Copy generated reports for sharing or transferring into a bug-tracking system.

⚡ Improved QA Efficiency: Reduce repetitive documentation and spend more time testing and validating defects.


🚀 How to Use BugGenie

**Step 1: ** Open the Application

Navigate to the web application where you want to report a bug.

**Step 2:** Start Recording

Click the BugGenie extension icon and select Start Recording to begin capturing user interactions.

**Step 3:** Reproduce the Bug

Perform the actions required to reproduce the issue, such as clicking buttons, entering data, or navigating between pages.

**Step 4:** Stop Recording

Once the issue has been reproduced, click Stop Recording to stop capturing user interactions.

**Step 5:** Enter the Bug Description

Describe the issue clearly in the description field.


**Step 6:** Capture and Generate the Bug Report

Click Capture & Report Bug to collect the available information and generate a structured bug report.

**Step 7:** Review the Generated Report

Review the available details, including:

 - Page URL and title
 - Bug description
 - Steps to reproduce
 - Actual result
 - Expected result
 - Screenshot
 - Recorded user actions
 - Video recording, when available
-  Edit and save the Expected Result if required.

Step 8: Copy and Report the Bug

Copy the generated report and paste it into Jira or your preferred bug-tracking tool.
